What is AccountIQ?

AccountIQ connects to a company's ERP data — Tally exports, Zoho Books, or raw General Ledger files — and lets finance teams query their books in plain English, run GST and TDS compliance checks, and receive daily automated alerts. No SQL knowledge needed. No waiting for a data analyst or CA.

Core insight: Indian SMEs lose real money every month because vendors don't file their GSTR-1 on time — blocking Input Tax Credit without warning. AccountIQ is the only product that proactively tracks this at the invoice level, before the government reversal notice arrives.

Complete User Journey

1 Sign Up & Onboard

User signs up at acctqai.com. After email verification, a short wizard collects company name, ERP type (Tally / Zoho Books / File Upload), and role (CFO / Finance Manager / Accountant). Takes under 2 minutes.

2 Connect Data — Upload Files

User goes to Connections → New and uploads an Excel or CSV export from their ERP. The system auto-detects the document type by scoring column headers:

  • GL — transaction_date, voucher_type, debit/credit amounts
  • GSTR-1 — gstin_of_recipient, outward supply columns
  • GSTR-2B — supplier_gstin, itc_eligibility columns
  • Form 26Q — deductee_pan, tds_amount columns
  • GSTR-3B, ITR, OTHER

User confirms the detected type and data period. File is parsed into a structured database table. Data is retained for 90 days (users re-upload monthly, matching their filing cycle).

3 Query Studio — Ask AI

User opens a GL connection and clicks Ask AI. They type questions in English, Hindi, or Hinglish:

  • "May mein kitna GST pay karna hai?"
  • "Show overdue debtors above 60 days"
  • "Top 5 vendors by spend this quarter"
  • "Cash and bank balance as of today"

How the Query Pipeline Works

Every question passes through 4 layers in order. Each layer is cheaper and faster than the next. A query stops at the first layer that can answer it.

Layer 1 — Template Engine
50+ hand-written SQL templates · ₹0 cost · <50ms · handles ~70% of queries
Matched by keyword/regex patterns on the question. Returns SQL instantly with 100% accuracy. The template library encodes Indian SME finance knowledge — Tally voucher types, GST naming, Hindi/Hinglish patterns.
↓ no match
Layer 2 — RAG (Past Q→SQL pairs)
~₹0.001/query · 100–200ms · handles ~20% of queries
Retrieves the 3 most similar past questions, injects them as few-shot examples into the LLM prompt. Every query run by any user improves accuracy for all future similar queries.
↓ LLM called with context
Layer 3 — LLM (Last Resort)
Groq Llama 3.3 70B (free) for simple · Claude Haiku for complex · handles <10% over time
Result is stored back to RAG so the same question never hits the LLM twice. Cost per query decreases as usage grows.
↓ SQL error
Layer 4 — Execution Feedback Loop
SQL error sent back to LLM → retry once
Catches column name mismatches and syntax errors automatically.
Privacy guarantee: Before any LLM sees data, a tokeniser masks all PII. Vendor names become VENDOR_T001, amounts become AMT_T002. Real customer data never leaves the server in LLM prompts.
4 Compliance Reconciliation

User goes to a connection → Reconcile tab. Selects a second compliance document to compare against. The system runs automated matching and surfaces every gap.

Three Reconciliation Types

GL ↔ Form 26Q (TDS Reconciliation)

Checks payment entries in the GL against TDS deducted in the 26Q return. Finds: payments above ₹30K where TDS wasn't deducted, wrong rates applied, missing deductee PANs.

GL ↔ GSTR-1 (Outward Supply Reconciliation)

Checks sales invoices in the GL against what was reported in the GSTR-1 filing. Finds: invoices filed but not in GL, amount mismatches, party name discrepancies.

GL ↔ GSTR-2B (Vendor ITC Reconciliation) — Our Moat

Checks purchase invoices in the GL against the government's GSTR-2B inward supply statement. This is what no other tool does proactively.

Gap Code Severity What it means Business impact
G2BGL-002 Critical GL has invoice, GSTR-2B doesn't Vendor hasn't filed GSTR-1 — ITC will be blocked on reversal
G2BGL-003 Review GSTR-2B has invoice, GL doesn't ITC is available but was never booked — free money left unclaimed
G2BGL-004 Review Matched, but ITC marked ineligible Credit blocked — shown with exact reason from GSTN
G2BGL-005 Review Vendor name mismatch on same invoice Possible wrong-vendor booking in GL
G2BGL-001 Info Overall purchase vs taxable total variance Summary-level mismatch flag
5 Vendor ITC Scorecard

After reconciliation runs, per-vendor compliance scores are persisted permanently (surviving the 90-day file expiry). User goes to Vendor ITC Scorecard on the connection page to see:

  • Red vendors — >30% of invoices at risk across trailing periods
  • Amber vendors — 10–30% at risk, watching
  • Green vendors — ≤10% risk, consistently filing
  • ₹ ITC at risk per vendor for the current period
  • Period-by-period history table per vendor — expandable

This is the first time Indian SMEs can see which vendors are a compliance risk before the government reversal notice arrives.

6 Daily Pulse — Automated Alerts

User enables Daily Pulse on a connection. Every morning at 8 AM, the system automatically:

  • Computes a financial snapshot (account balances, movement totals)
  • Checks for TDS gaps on recent payment entries
  • Checks for vendor GST filing risk from persisted compliance records
  • Alerts on upcoming compliance deadlines (GSTR-1 due, advance tax dates)
  • Emails the admin a severity-coded digest
  • Stores the digest in-app for review anytime

Cadence: Daily or Weekly. Individual alert categories can be snoozed.
